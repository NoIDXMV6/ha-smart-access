# DOCS.md — Smart Access Core (справка аддона)

Краткая справка отображается в карточке аддона.

## Установка и настройка (кратко)

Полное пошаговое руководство — в [README репозитория](https://github.com/NoIDXMV6/ha-smart-access#установка-по-шагам). Ключевые моменты:

1. **Mosquitto broker** установлен и запущен. Пользователя MQTT для Frigate
   создайте через Настройки → Люди → Пользователи (проще всего) или в аддоне
   Mosquitto, секция Logins. Имя не может быть `homeassistant`/`addons`.
2. **Frigate** ставится из репозитория аддонов
   `https://github.com/blakeblackshear/frigate-hass-addons`
   (главный репозиторий `blakeblackshear/frigate` магазин не примет —
   там нет аддонов).
3. **Конфиг Frigate** вводится не на странице «Конфигурация» аддона, а в
   веб-интерфейсе Frigate (редактор конфигурации) или в файле
   `/addon_configs/ccab4aaf_frigate/config.yml`. Проще всего сгенерировать
   кнопкой «Сгенерировать» в панели Smart Access и вставить.
4. Этот аддон: заполните поля в UI (камеры, исполнители, пороги, VLM) —
   без правки файлов — и нажмите «Запустить». Установка — скачивание готового
   образа ~0,5 ГБ с прогрессом в карточке аддона (1–5 минут), ничего на
   устройстве не собирается.
5. MQTT-поля в настройках аддона можно оставить пустыми: учётные данные
   брокера берутся у Supervisor автоматически.
6. **Интеграция Smart Access (HACS) — обязательный второй компонент**, из того же
   репозитория: она создаёт сенсоры `sensor.smart_access_*`, сервисы
   `smart_access.enroll/identify` и кнопку «Обучить» на карточках. Аддон без
   неё не управляет HA, интеграция без аддона не получает данные.

## Что делает

* Раздаёт камеры HA (включая облачные А.М.Видео/ЕГДС) локальным MJPEG-потоком
  для Frigate: из сети аддона Frigate поток доступен как
  `http://172.30.32.1:8100/mjpeg/<name>` (шлюз hassio-сети = хост, где слушает
  этот аддон; генератор конфига подставляет его сам).
* Камеры с заполненным полем `rtsp_url` идут во Frigate напрямую (TCP-транспорт
  подставляется генератором), мост для них не тратит ресурсы.
* Слушает события Frigate (MQTT), распознаёт машины (CLIP, CPU) и лица (SFace).
* Открывает исполнителей через HA: `executor_service` + `executor_target`
  (например `amvideo.open_barrier` + `button.1_shlagbaum_..._otkryt`,
  `lock.unlock` + `lock.gate`).
* Ведёт базу «своих»: фото в `/media/smart_access/{cars,faces}/<имя>/`,
  эмбеддинги в `/data/db/`.

## Обучение

* Кнопка «Обучить» на карточке → сервис `smart_access.enroll`.
* Или панель Smart Access (боковая панель): загрузка фото файлом, удаление, тест.

## VLM (опционально)

OpenAI-совместимый endpoint: `base_url` (например `http://192.168.1.50:11434/v1`),
`api_key`, `model` (например `moondream`). Режимы: `gray_zone` (рекомендуется),
`verify_all`, `off`. При недоступности решение остаётся за локальными моделями.

## Журнал и события HA

* Сенсоры: `sensor.smart_access_status`, `sensor.smart_access_last_event`.
* События: `smart_access_event` (допуск/отказ/обучение), `smart_access_ack`.

## Диагностика

* Лог аддона: очередь событий, score матчей, ошибки MQTT/Frigate.
* Панель: счётчики сбоев камер моста, состояние моделей, статус Frigate —
  при «нет связи» панель показывает точную причину и что сделать.

## frigate_url и порты аддона Frigate

* Правильное значение: `http://127.0.0.1:5000` (HTTP API Frigate). Порт 5000
  должен быть опубликован: Frigate → Конфигурация → Сеть → поле
  «Unauthenticated Web interface» → `5000` → Сохранить.
* Частая ошибка — указать `8556`: это WebRTC (go2rtc), там нет API; 8554 —
  RTSP, 8971 — авторизованный web UI, 1984 — go2rtc API.
* Если связь не появляется, откройте панель Smart Access — в карточке
  «Состояние» будет конкретная причина.
