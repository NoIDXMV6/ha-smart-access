# 1.1.1

- Исправление: `webui` приведён к формату Supervisor `http://[HOST]:[PORT:8099]`.
  Прежнее значение не проходило валидацию `config.json`, из-за чего Supervisor
  молча пропускал аддон при сканировании репозитория — Smart Access Core не
  появлялся в Магазине аддонов.

# 1.1.0

- Новое поле камеры `rtsp_url`: локальные RTSP-камеры (калитка/домофония Hikvision
  и т.п.) идут во Frigate напрямую, `preset-rtsp-tcp` подставляет генератор;
  MJPEG-мост для таких камер не запускается (экономия CPU).
- Панель: таблица камер различает «прямой RTSP» и MJPEG-мост.

# 1.0.0

- Первый релиз: MJPEG-мост для облачных камер, распознавание машин (CLIP int8, CPU),
  лица (YuNet+SFace), enrollment по MQTT, UI-панель, опциональный VLM (OpenAI-compatible),
  kill-switch, журнал, генератор конфига Frigate.
