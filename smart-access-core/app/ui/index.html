Жесты — настраиваются для каждого лица

Жесты больше не жёстко заданы. Для каждого лица вы сами выбираете жест-подтверждение (калитка откроется, только когда лицо распознано и жест показан) и, при желании, тревожный жест (калитка открывается И одновременно звонит тревога — незаметный сигнал «меня держат»). Выбирайте обычные жесты, не привлекающие внимания: коснуться носа или уха, знак V или OK, палец вверх/вниз — можно показать одной рукой с сумками в другой или когда сзади стоит посторонний.

Проверка жеста на кадре

Загрузите фото или снимите кадр с камеры — панель покажет, какие из настроенных жестов лица она видит и с какими оценками. Так проверяют и обучение (фото кисти), и срабатывание.

Конфиг Frigate (генератор)

Скопируйте в конфиг Frigate: веб-интерфейс Frigate → редактор конфигурации (или файл /addon_configs/ccab4aaf_frigate/config.yml). Страница «Конфигурация» аддона для этого не используется. Креды MQTT подставлены автоматически (Supervisor): если Frigate пишет MQTT Not authorized — замените блок mqtt в его конфиге этим блоком целиком.

Детектор: OpenVINO на CPU — GPU не требуется.
